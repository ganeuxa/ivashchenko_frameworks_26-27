# Система учёта расходных материалов

## Назначение

Приложение для учёта расходных материалов организации: какие материалы есть,
на каких складах они хранятся, сколько их осталось и какие операции прихода
и расхода с ними проводились. Система помогает вовремя замечать заканчивающиеся
материалы и не допускает списания больше, чем есть на складе.

## Целевая аудитория

- кладовщики и заведующие складом: оформляют приход и расход материалов;
- сотрудники хозяйственного отдела и снабжения: следят за остатками и
  планируют закупки;
- руководители подразделений: просматривают расход материалов.

## Предметная область

Организация (офис, учебное заведение, мастерская) постоянно расходует
материалы: бумагу, картриджи, канцелярию, чистящие средства, запчасти. Материалы
хранятся на одном или нескольких складах. Любое движение материала оформляется
операцией: приход увеличивает остаток на складе, расход уменьшает. Остаток
показывает, сколько единиц материала сейчас есть на конкретном складе. Если
остаток опускается ниже минимального уровня, материал нужно дозаказать.

## Основные сущности

- **Материал**: наименование, единица измерения, минимальный остаток;
- **Склад**: название и местоположение места хранения;
- **Операция**: приход или расход материала на складе с указанием количества
  и даты;
- **Остаток**: текущее количество материала на конкретном складе.

## Основные функции

- оформление прихода материала на склад (увеличение остатка);
- оформление расхода (списания) материала с проверкой достаточности остатка;
- контроль минимального остатка и предупреждение о необходимости дозаказа;
- просмотр текущего остатка материала на складе;
- просмотр истории операций (планируется).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
python main.py
```

## План развития

На следующих этапах планируется:

- консольная программа с несколькими материалами, складами и историей операций;
- реализация сущностей в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и разграничение прав (кладовщик, администратор);
- разработка REST API;
- автоматизированное тестирование;
- контейнеризация приложения (Docker);
- настройка CI/CD.
