# Система учёта расходных материалов

Консольное приложение для учёта расходных материалов по складам: приход,
расход, перемещение и контроль остатков.

## Назначение

Приложение ведёт учёт расходных материалов: что есть в наличии, на каком складе
лежит и сколько осталось. Каждый приход и расход записывается как операция.
Программа не даст списать больше, чем есть на складе, и предупредит, когда
материал пора докупать.

## Целевая аудитория

Кладовщики, которые принимают и выдают материалы. Сотрудники хозотдела и
снабжения: им нужно видеть остатки, чтобы вовремя заказывать новое. Руководители
подразделений, которым интересно, сколько тратит их отдел.

## Предметная область

В любом офисе, колледже или мастерской постоянно уходят бумага, картриджи,
канцелярия, моющие средства, мелкие запчасти. Всё это хранится на одном или
нескольких складах. Когда материал привозят, оформляют приход, и остаток растёт.
Когда выдают, оформляют расход, и остаток уменьшается. У каждого материала есть
минимальный остаток: если на всех складах вместе осталось меньше, материал надо
дозаказать.

## Основные сущности

- Материал: наименование, единица измерения, минимальный остаток.
- Склад: название и где он находится.
- Операция: приход, расход или перемещение, материал, склад, количество и дата.
- Остаток: сколько единиц материала сейчас лежит на конкретном складе.

## Возможности

- просмотр списка материалов с общим остатком и статусом;
- поиск материала по части названия;
- добавление материалов и складов;
- просмотр остатков на выбранном складе;
- приход материала на склад;
- расход с проверкой, хватает ли материала;
- перемещение материала между складами;
- история операций и отмена операции с пересчётом остатков;
- список материалов, которые пора дозаказать.

Все изменения сразу сохраняются в JSON-файлы, так что после перезапуска данные
остаются. Неправильный ввод (буква вместо числа, несуществующий номер) и битые
файлы данных программу не роняют.

## Структура проекта

```
main.py          меню и вывод на экран
materials.py     работа с материалами: добавление, поиск, сортировка
warehouses.py    работа со складами
stock.py         остатки: подсчёт, изменение, статус, что дозаказать
operations.py    приход, расход, перемещение, отмена операций
storage.py       загрузка и сохранение JSON
utils.py         ввод чисел и строк с проверкой, номера, дата
data/            файлы с данными
tests/           тесты pytest
```

## Формат данных

Данные лежат в папке `data/`, в каждом файле список записей.

`materials.json`:

```json
[{"id": 1, "name": "Бумага офисная А4", "unit": "пачка", "min_balance": 10}]
```

`warehouses.json`:

```json
[{"id": 1, "name": "Склад №1", "location": "корпус А, 1 этаж"}]
```

`stock.json`, один остаток на пару «материал, склад»:

```json
[{"material_id": 1, "warehouse_id": 1, "quantity": 40}]
```

`operations.json`, тип операции бывает `receipt` (приход), `write_off` (расход)
и `transfer` (перемещение, тогда заполнен `target_warehouse_id`):

```json
[{"id": 1, "type": "receipt", "material_id": 1, "warehouse_id": 1,
  "target_warehouse_id": null, "quantity": 40, "date": "2026-09-01 10:15"}]
```

В программе материалы и склады хранятся в словарях по номеру, остатки в словаре
с ключом-кортежем `(material_id, warehouse_id)`, операции в списке словарей.

## Требования

- Python 3.10 или новее;
- pytest и flake8 (только для разработки).

Установка:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```
